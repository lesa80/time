# Проверка проекта Raketa для macOS

Дата: 18 октября 2026. Исторический аудит версии 2.0; изменения 2.1 перечислены в CHANGELOG.md. Область: нативное приложение, подготовка ресурсов, сборка, тесты и описание проекта. Результат относится к версии 2.0. Это техническое ревью, а не подтверждение допуска к распространению Apple.

## Сверка с документацией Apple

- **Login Items:** используется современный [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice) для macOS 13+. Состояние переключателя читается из системного сервиса. Автозапуск меняется только по явному действию пользователя; tests не вызывают register/unregister.
- **Энергопотребление:** учитывается [occlusionState](https://developer.apple.com/documentation/appkit/nswindow/occlusionstate-swift.property) именно окна часов. Видимость значка в строке меню не используется как повод постоянно рисовать скрытое окно. У повторяющегося таймера задан [tolerance](https://developer.apple.com/documentation/foundation/timer/tolerance).
- **Privacy:** [CA92.1](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons) соответствует чтению и записи собственных UserDefaults. Manifest описывает отсутствие tracking и сбора данных. Добавление manifest само по себе не подтверждает соответствие всем правилам магазина.
- **Распространение:** [Apple требует Developer ID и Hardened Runtime для нотариализации](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution). Hardened Runtime включён, сертификат можно передать через RAKETA_SIGN_IDENTITY. По умолчанию используется ad-hoc, нотариализация не выполняется.

Статус локальной версии: самостоятельное несандбоксированное приложение для рабочего стола. Оно не публикуется в Mac App Store и не является системным WidgetKit-расширением.

## Автоматические проверки

1. Node.js: время, реестр, исходные PNG, прозрачность, общие оси, 12/24-часовые циклы и обратный ход.
2. Swift: модели, недопустимые данные и пути, строгий CLI, расположение на мониторах и политика анимации.
3. AppKit: клик, дрожание указателя, drag, возврат drag, контекстный клик, отпускание снаружи и accessibility press.
4. Сравнение кэша ClockView и прямого CoreGraphics-рендера для 22 тем с безелем и без него.
5. Проверка сохранения вида в отдельном тестовом домене UserDefaults, сохранения предпочтительной ширины и остановки таймера во сне.
6. Сравнение 46 экспортов PNG шириной 2048 px с независимым resvg-эталоном, проверка точных ресурсов, иконок и manifest.
7. Universal binary, plist, Hardened Runtime, подпись и целостность итогового ZIP.

После переноса ресурсов 128 готовых PNG-слоёв сопоставлены с предыдущим архивом: совпадение побайтное. Темы и их оформление при очистке сохранены.

## Ограничения и проверки перед публичным выпуском

- Видимый интерфейс, ручная навигация VoiceOver, регистрация Login Item, несколько реальных мониторов, Stage Manager, полноэкранные приложения и смена пользователя требуют ручного тестирования. Автоматические AppKit-проверки используют скрытые окна и локальные bitmap-контексты; захват экрана не выполняется.
- На этой машине подтверждаются компиляция обеих архитектур и выполнение на Apple Silicon. Запуск на Intel и macOS 13 не проверен. Command Line Tools на этой машине выдаёт предупреждение линкера о libswiftCompatibilityPacks.a для x86_64; универсальный бинарник собирается, но проверка на Intel остаётся необходимой.
- В текущем архиве нет Developer ID и билета нотариализации. Для распространения подготовьте сертификат, пройдите notarytool, staple и проверку Gatekeeper на чистой машине.
- Для Mac App Store понадобятся отдельная проверка App Sandbox и требований магазина. Для системной галереи виджетов нужно отдельное расширение WidgetKit; высокая частота секундной стрелки не переносится туда автоматически.
- Материалы производителя и логотип не превращаются в свободно лицензированные из-за использования в неофициальном приложении. Права на распространение должны быть подтверждены отдельно.
