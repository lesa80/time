# Техническое состояние «Время» 2.5.0

Версия 2.5.0, сборка 28. Область: нативное приложение macOS, ресурсы, сборка и автоматические проверки. Описание технического состояния не является сертификацией Apple.

## Архитектура и системные возможности

| Область | Реализация |
|---|---|
| Интерфейс | AppKit, прозрачное окно часов и значок в строке меню; изоляция интерфейса через `@MainActor` |
| Компиляция | Swift 6, предупреждения как ошибки, arm64 и x86_64, минимальная macOS 13 |
| Отрисовка | CoreGraphics; кэш неподвижных слоёв в масштабе экрана, отдельная отрисовка движущихся стрелок |
| Жизненный цикл | Остановка таймера при сне и перекрытии окна, восстановление после пробуждения, освобождение наблюдателей при выходе |
| Анимация | До 30 кадров/с, до 15 в Low Power Mode, обновление раз в секунду при Reduce Motion |
| Настройки | Локальные UserDefaults; сохранение положения с задержкой, в конце перетаскивания и при завершении |
| Геометрия | Предпочтительная ширина окна, вписывание в доступную область монитора, проверка сохранённых координат |
| Ресурсы | Проверка реестра, размеров, типов и порядка слоёв, осей стрелок и путей перед отрисовкой |
| CLI | Строгий разбор параметров; ошибочный экспорт завершается с ненулевым кодом без открытия GUI |
| Доступность | Действия VoiceOver для часов и открытия меню; автоматический контраст значка строки меню |
| Автозапуск | SMAppService; изменение только по действию пользователя, состояние читается из macOS |
| Приватность | Privacy manifest, отсутствие аналитики и фоновых сетевых запросов |
| Упаковка | Чистая staging-сборка, проверка ресурсов и подписи, упаковка ZIP после успешных проверок |

## Локализация

Русский, английский, немецкий, французский и испанский интерфейс. Ресурсы `.lproj` входят в приложение; основной язык macOS выбирается при запуске, неподдерживаемый язык заменяется английским. Переведены меню, названия тем, справка, подсказки, сообщения об ошибках и VoiceOver.

## Автоматические проверки

- 33 JavaScript-теста: время, реестр 25 тем, PNG, прозрачность, общие оси, 12/24-часовые циклы, палитра и обратный ход.
- Swift: модели, недопустимые данные и пути, CLI, геометрия окна и политика анимации.
- AppKit: клик, перетаскивание, контекстное меню, accessibility press, сохранение вида, предпочтительной ширины и остановка таймера во сне.
- Сравнение кэша `ClockView` с прямой отрисовкой для 25 тем в двух видах.
- 59 сравнений CoreGraphics-экспорта PNG с независимым resvg-эталоном при ширине 2048 px.
- Проверка реального bundle в отдельных процессах для пяти языков и английского fallback при неподдерживаемом основном языке; меню и окно «О часах» проверяются при ширине 640/960 точек в светлом и тёмном оформлении.
- Проверка universal binary, Info.plist, privacy manifest, Hardened Runtime, подписи и итогового ZIP.

Локальные проверки выполнены на macOS 26.6.2, arm64. Проверки AppKit используют скрытые окна и собственные bitmap-контексты, не захватывают экран и не меняют системный автозапуск. Актуальные результаты на runner GitHub доступны в [Actions](https://github.com/lesa80/time/actions/workflows/ci.yml).

## Распространение и ограничения проверки

Текущая тестовая сборка подписана ad-hoc с Hardened Runtime, без Developer ID и нотариализации Apple. Настройка сертификата для сборки — `VREMYA_SIGN_IDENTITY`. Приложение работает как самостоятельная программа для рабочего стола.

Ручные проверки VoiceOver, автозапуска, нескольких мониторов, Stage Manager и полноэкранных приложений остаются отдельным этапом. Выполнение на Intel и минимальной macOS 13 локально не подтверждено; успешная компиляция обеих архитектур не заменяет запуск на соответствующей системе.
