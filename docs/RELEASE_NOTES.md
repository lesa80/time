# Время 2.9.3 — тестовая сборка

Сборка 51 для macOS 13 и новее. Один архив подходит для Mac с Apple Silicon и Intel. [Скачать приложение](https://github.com/lesa80/time/releases/download/v2.9.3/Vremya-2.9.3-macOS-universal.zip)

## «Ракета» — «Города 0343»

В коллекции появилась 41-я тема. У «Городов» часовая стрелка делает один оборот за сутки. Полночь находится внизу, а диск с названиями городов вращается вокруг неподвижной карты Арктики. [Модель на сайте «Ракеты»](https://raketa.com/product/goroda)

- Наведите указатель на верхнюю правую головку или названия городов. Прокручивайте двумя пальцами, колесом мыши или перетаскивайте диск. Один шаг в любую сторону равен одному часу (15°). Стрелки показывают системное время macOS.
- Чтобы прочитать время в другом городе, совместите свой город с отметкой текущего часа. Например, в 08:09 в Москве поставьте «Москва» напротив 08. Напротив Пекина окажется 13, а минуты те же — в Пекине 13:09. На диске указаны стандартные часовые пояса.
- В режиме без корпуса вращайте сам диск. Через меню **Interaction** можно сдвинуть его на час или вернуть исходное положение. Приложение запоминает выбранное положение между запусками.

## Установка и проверка

1. Завершите предыдущую копию приложения.
2. Распакуйте `Vremya-2.9.3-macOS-universal.zip`, перенесите `Время.app` в «Программы» и откройте.
3. Выберите **Тема → Ракета → Города 0343**.

Тестовая сборка подписана ad-hoc и распространяется без нотариализации Apple. Для проверки архива скачайте файл контрольных сумм в ту же папку и выполните команду. [Скачать SHA256SUMS](https://github.com/lesa80/time/releases/download/v2.9.3/SHA256SUMS)

```sh
shasum -a 256 -c SHA256SUMS
```

На Apple Silicon прошли 43 JavaScript-теста, нативные тесты AppKit, проверки пяти языков и 91 растровое сравнение. Для нового диска проверены шаг в обе стороны, переход через ноль и восстановление положения после перезапуска. [GitHub Actions](https://github.com/lesa80/time/actions)
