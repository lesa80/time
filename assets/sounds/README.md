# Звук кнопок

`gshock-button.wav` — оригинальный синтезированный короткий электронный писк для кнопок темы G‑Shock. Это собственный ресурс проекта, без записей настоящих часов и сторонних сэмплов.

- WAV, линейный PCM, 16 бит, моно, 44 100 Гц.
- Длительность: 80 мс.
- Основная частота: 4096 Гц; третья гармоника с относительной амплитудой 0,08.
- Амплитуда ограничена 18% цифровой шкалы; за время сигнала плавно уменьшается до 72% начальной.
- Косинусное нарастание и затухание по 2 мс исключают щелчки на краях.

Воспроизводимое создание из корня проекта:

```sh
node scripts/prepare-sounds.mjs
```

При сборке ресурс копируется в `Contents/Resources/GShockButton.wav`.
