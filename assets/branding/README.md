# Оформление «Время»

Оригиналы изображений предоставлены пользователем 18 октября 2026 года:

- `bolt42.png` — логотип БОЛТ42 для раздела «Разработка» в «О часах» и циферблатов «Минимализм». В циферблатах используется исходная надпись без слогана; на тёмном фоне буквы адаптированы в белый, красное 42 сохранено.
- `time-icon.png` — квадратное изображение «ВРЕМЯ · 21:42» для иконки приложения.

Файлы сохранены без изменения. Размеры и SHA-256 можно сверить с `sources.json`. Скрипт `scripts/prepare-icons.mjs` масштабирует изображение иконки для стандартного набора macOS и помещает его на скруглённую плитку с прозрачными внешними полями. Изображение не перерисовывается. Логотип копируется в ресурсы приложения без изменения байтов и показывается на светлой подложке.
