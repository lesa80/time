# Безопасность

## Поддерживаемые версии

Исправления безопасности предназначены для текущей ветки разработки и версии 2.5.0. Поддержка macOS начинается с 13; фактически проверенные платформы перечисляются в README и описании релиза.

## Как сообщить об уязвимости

В опубликованном репозитории используйте **Security → Advisories → Report a vulnerability**, если владелец включил private vulnerability reporting. Опишите затронутую версию, условия воспроизведения, влияние и минимальный пример. Не прикладывайте настоящие пароли, ключи, персональные данные и действующие токены.

Если приватная форма недоступна, создайте обычный Issue только с просьбой предоставить приватный канал связи — без технических деталей уязвимости. Форма «Вопрос» подходит для такой просьбы. Целевой репозиторий — `lesa80/time`, владелец — GitHub [@lesa80](https://github.com/lesa80). Приватный email не опубликован; для технических деталей используйте приватную форму после её включения владельцем.

Сообщения рассматриваются по возможности; фиксированного срока ответа проект не обещает. Пожалуйста, согласуйте публичное раскрытие до публикации эксплойта.

## Область проекта

Приложение работает локально, не имеет аккаунтов, аналитики и фоновой сети. Экспорт PNG работает с явным путём пользователя. Файлы тем в текущем интерфейсе не импортируются из внешних источников. Превью-сервер предназначен только для разработки и слушает `127.0.0.1`; его не следует выставлять в интернет.

Локальные сборки подписаны ad-hoc, без нотариализации. Отсутствие сертификата Developer ID не является само по себе уязвимостью кода; статус подписи должен быть явно указан у распространяемого архива.

## Для владельца репозитория

В настройках репозитория включите private vulnerability reporting и проверьте доступность формы, secret scanning/push protection и настройки GitHub Actions. Эти настройки нельзя включить добавлением данного файла. Секреты подписи и нотариализации должны оставаться в Keychain или GitHub Secrets и не использоваться в проверках недоверенных pull request.
