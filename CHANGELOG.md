# Время 2.9.2

23 октября 2026 года. Сборка 50.

- Таймер обратного отсчёта G-Shock сохраняет оставшееся время, запуск/паузу, автоповтор и выбранный режим. После перезапуска учитывается время при закрытом приложении, включая перезагрузку Mac.
- Ручная пауза и сброс сохраняются; изменение длительности очищает прежнее измерение.
- Если срок истёк при закрытом приложении, при следующем запуске подаётся один сигнал. Обработанное завершение не повторяется при каждом перезапуске; автоповтор сохраняет положение внутри текущего цикла без серии пропущенных сигналов.
- Сохранена совместимость с данными хронографов и секундомеров версии 2.9.1. Обновлены README на двух языках, инструкции G-Shock и справка на пяти языках.
- Пройдены 42 JavaScript-теста, нативные проверки моделей, сохранения, восстановления и взаимодействий AppKit, проверки пяти языков и 89 сравнений растрового экспорта. Универсальная ad-hoc сборка для macOS 13+, Apple Silicon и Intel.

# Время 2.9.1

23 октября 2026 года. Сборка 49.

- Speedmaster, Navitimer, Chronostop и секундомер G-Shock автоматически сохраняют время старта и состояние при действиях пользователя и завершении приложения.
- Запущенные измерения продолжаются после перезапуска с учётом времени при закрытом приложении и перезагрузке Mac. Ручная пауза исключает этот интервал; сброс очищает сохранённый отсчёт.
- Сохраняются промежуточный результат и режим секундомера G-Shock, а также зафиксированное через меню показание Chronostop. Таймер обратного отсчёта G-Shock остаётся в рамках одного запуска.
- Обновлены справка на пяти языках, русский и английский README и инструкции моделей.
- Пройдены 42 JavaScript-теста, нативные проверки сохранения и восстановления, взаимодействия AppKit и пяти языков, 89 сравнений растрового экспорта. Универсальная ad-hoc сборка для macOS 13+, Apple Silicon и Intel.

# Время 2.5.0

Версия от 19 октября 2026 года. Сборка 28.

- Интерфейс на русском, английском, немецком, французском и испанском. По умолчанию используется основной язык macOS; для неподдерживаемого языка — английский. Переведены меню, справка, названия тем, подсказки, ошибки и VoiceOver.
- 25 растровых тем: четыре варианта «Минимализма» с 12- и 24-часовыми шкалами в светлом и тёмном оформлении и 21 тема производителя в разделе «Ракета».
- Тема по умолчанию — «Минимализм 24 — тёмный». Цветные сектора 24-часовых циферблатов, крупные цифры и контрастные стрелки.
- Логотип БОЛТ42 под центром собственных циферблатов; над центром — массивный контур болта на плоскости с диагональной штриховкой.
- Переключение отдельного циферблата и полного вида с корпусом и ремешком по клику, перемещение и закрепление окна.
- Значок в строке меню: левый клик переключает «Поверх окон», правый открывает настройки. Автозапуск управляется через macOS.
- Окно «О часах» с прокручиваемыми разделами справки, коллекции, лицензий и разработки.
- Нативное приложение AppKit для macOS 13+, универсальный бинарник Apple Silicon и Intel. Локальная сборка подписана ad-hoc, без нотариализации Apple.
- Локальные проверки: 33 JavaScript-теста, нативные сценарии AppKit и 59 сравнений экспорта PNG. Результаты CI — в [GitHub Actions](https://github.com/lesa80/time/actions).
- Код — MIT. Права на БОЛТ42 и иконку сохраняются за автором; источники графики и область лицензии описаны отдельно.
